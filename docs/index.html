Why it exists

The problem

Fully autonomous agents make costly mistakes. Before a high-stakes transaction an agent needs a way to halt and ask a real person — and no API marketplace sells human judgement with an SLA attached.

The answer

A universal human arbiter any agent can hire on-chain. It bridges autonomous execution and a real person over Telegram, escrow-backed, with an automatic refund if nobody answers in time.
