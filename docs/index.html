The Problem & Solution

The Problem

Fully autonomous agents can make costly mistakes. Before executing a high-stakes transaction, agents need a reliable way to halt and ask a human for permission.

The Solution

Summon is a universal human-in-the-loop agent that bridges on-chain AI with real-time human communication over Telegram — a secure yes/no sign-off, escrowed on-chain.

Key Features

What Summon does

⚡

Instant Notification

Pushes agent requests directly to your Telegram.

🔒

Secure Sign-off

Only authorized Telegram users can approve or reject.

🎨

Seamless Integration

Any A2A agent can hire Summon as its human arbiter.

🔄

State Recovery

Re-evaluates active sign-off requests on startup — no lost approvals.

💼

Dynamic Payout

Routes earned USDC to a custom wallet via SUMMON_PAYOUT_ADDRESS.
